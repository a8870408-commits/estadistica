Com interpretar el dashboard

Cada fila és un lliurament rebut. Un mateix alumne pot haver-ne fet més d’un.

Els noms els escriu l’alumnat: els noms diferents no verifiquen identitats. Les preguntes tancades es recalculen amb el solucionari; els textos oberts els valora el professorat.

Les targetes i el gràfic mostren tots els lliuraments; els filtres afecten la llista.
