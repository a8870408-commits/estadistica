# Aula oberta · Estadística
Aplicació educativa en català per a 1r d’ESO: dades i variables, freqüències i gràfics, mitjana, mediana i moda. Inclou un laboratori numèric, cinc reptes amb retorn explicatiu i progrés local al navegador. No requereix comptes ni serveis externs; la tipografia té alternatives locals.

## Executar
Des del repositori, executa `npm start` (requereix Python 3). L’aplicació se serveix al port 3000. També es pot publicar en qualsevol allotjament estàtic.

## Validar
`npm test` executa les proves dels càlculs amb Node.js. No hi ha dependències per instal·lar.
